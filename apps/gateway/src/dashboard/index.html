Paste your gateway's operator token. It is kept for this tab only and sent only to this gateway.

Where do I find my token?
  1. Open a terminal in the Tollgate folder on the computer that runs the gateway.
  2. Run grep GATEWAY_OPERATOR_TOKEN .env. Paste everything after the =.
  3. No .env file yet? Run pnpm onboard first. It creates one with a random token.
  4. Running pnpm demo --serve or the sandbox? They print their own token when they start. Use that one.

The token is your owner password. Never share it or commit it. To change it, edit GATEWAY_OPERATOR_TOKEN in .env (16 characters or more) and restart the gateway.
